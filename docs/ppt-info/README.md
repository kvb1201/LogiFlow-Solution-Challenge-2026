# LogiFlow — Solution Challenge 2026 PPT Kit

Content for the **Google Solution Challenge 2026** prototype deck (16 slides). Use your team’s copy of the official template.

## How to use

1. **Make a copy** of the Google template (do not edit the master).
2. Open the matching file in `slides/` for each slide number.
3. Copy **Title**, **Body**, and **Bullets** into the template placeholders.
4. Insert ready-made PNGs from `diagrams/` (**already exported**) or re-export from `.mmd` via [mermaid.live](https://mermaid.live) → slides **6**, **7**, **8**.
5. For slide **11**, capture screenshots listed in `slides/11-mvp-snapshots.md`.
6. Fill **team-specific** placeholders in slide 2 and 13 (`[TEAM NAME]`, video URL, etc.).

## SDG alignment (mention on slide 3 or 4)

## Diagram export tips (single slide)

- Use **landscape** export, width **1920px** or **1600px**.
- Prefer **architecture-slide.mmd** and **process-flow-slide.mmd** — designed for one slide each.
- In PowerPoint: insert image → crop to content area; keep 12–15% margin for template header/footer.
